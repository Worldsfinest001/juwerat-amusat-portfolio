Build: `npm run build`

- juwerat-hero.jpg

- project-expense.jpg
- project-research.jpg
- project-gmail.jpg

- project-travel.jpg
- project-ebook.jpg
- project-calendar.jpg

Missing images automatically show designed placeholders. Replace `hello@example.com` in `src/main.jsx` before launch.
